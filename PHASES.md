# Gathr — Phase History

> Archived build log. One line per phase. For current stack, architecture decisions, file map, and open issues see `PROGRESS.md`.

- **Phase 0 — Project Scaffold:** strict tsconfig, ESLint+Prettier, `@/` aliases, feature-driven dirs; `mediaLibrary.ts` single gateway enforced via `no-restricted-imports`.
- **Phase 1 — Gallery Grid:** `getPhotosByDate/RecentPhotos/ByDateRange`; `galleryStore`; `useGallery` (infinite scroll + addListener refresh); `PhotoGrid` (FlashList, date headers, drag-select PanResponder); `PhotoThumb`; `DateSectionHeader`.
- **Phase 2 — Bulk Selection:** `selectionStore` (Set, toggle/range/all/byDate/byMonth); `SelectionBar` Select-All pill; FloatingTabBar selection mode (count + Share/Export/Add/Delete + Cancel); `useSelectionActions`; drag-to-select hit-test via cumulative Y offsets.
- **Phase 3 — Private Albums:** `db.ts` (WAL+FK; albums, album_assets, trips, favorites, trip_album_dismissed); `albumStore`; `useBiometricAuth` (local-auth + secure-store); `album/[id].tsx` biometric gate + grid + picker; Albums tab (create/delete/search/sort/import).
- **Phase 4 — Trip & Event Grouping:** `tripGrouper.ts` (6hr gap, ≥4 photos, reverse geocode cover); `geocoding.ts` (city→district→region→country cascade); trips `place` column via ALTER+try/catch; atomic DELETE+re-INSERT; `tripStore`; TripCard/TripsSection/trips tab/trip detail; location clustering.
- **Phase 5 — Photo Detail Viewer:** `photo/[id].tsx` full-screen horizontal pager; context-aware list (gallery/album/trip/memory/single); `initialScrollIndex`+`getItemLayout`; fade overlays auto-hide; footer actions (share/album/favorite/delete/rotate/flip).
- **Phase 6 — Sharing:** `sharing.ts` (shareAsset, shareMultipleAssets, saveAssetToLibrary); wired into detail footer + SelectionBar.
- **Phase 7 — UI Polish:** glassmorphic FloatingTabBar; full dark/light theme system + ThemeProvider/useTheme; GlassView (expo-blur); skeleton loaders; expo-image transitions; press spring animations; Stack header theming; safe-area padding.
- **Phase 8 — Native Album Import + Fixes:** `nativeAlbumImport.ts` (skip system albums, dedupe by name); `new Asset(assetId)` direct instantiation in album detail; numeric media-store ID descending order; `ScrollIndicator`.
- **Phase 9 — Gestures + Video:** RNGH pinch-zoom 1×–5× + clamped pan; double-tap zoom; conditional pan exclusion for paging; `isZoomedShared` worklet guard; long-press peek modal; expo-video `VideoPage` w/ glass controls; drag-to-select restored via `listHeaderHeightRef`.
- **Phase 10 — Performance:** module-level creation-time cache (batch 20); `memo`+`useCallback` on PhotoThumb/PhotoGrid/detail; `InteractionManager` deferred DB reads; synchronous gallery context init; pinch runOnJS guard; video interval only while playing.
- **Phase 11 — Smart Memories:** `memories.ts` buildMemories (5 past years parallel + trip memories ±3 days); `memoriesStore` (load once/session, daily 9AM notification); MemoryCard/MemoriesSection; `memory/[id].tsx` (re-fetches day, context:'memory'); GalleryHeader stacking.
- **Phase 12 — Auto-Album Suggestions:** `trip_album_dismissed` table; `tripSuggestionStore` (filter dismissed, saveSuggestionAsAlbum); dismissible `TripSuggestions` cards.
- **Phase 13 — In-App Camera:** `camera.tsx` rebuilt; 4 modes (Photo/Video/Burst/Scan); pinch+tap zoom w/ 0.5×/1×/2×/5×; tap-to-focus ring; timer; grid; flash modes; video recordAsync+timer; 5-shot burst; live QR/barcode scanner.
- **Phase 14 — Bulk Export ZIP:** `exportZip.ts` (base64 read, fflate.zipSync level:0, share, temp cleanup); `ExportProgress` type; export button w/ live progress.
- **Phase 15 — Photo Search:** `PhotoSearchResults.tsx` (bare-year / month+year parsing, 350ms debounce, ByDateRange query); animated search bar + FAB in gallery.
- **Phase 16 — Image Editing:** `manipulateAsync` in detail `···` sheet; rotate/flip non-destructive (new asset), gallery auto-refresh.
- **Phase 17 — Notifications:** `notifications.ts` (foreground handler, DAILY 9AM reminder, idempotent); auto-triggered when memories first built, only if memories exist.
- **Phase 18 — Location + Clustering:** `geocoding.ts` getPlaceName (no GPS perm needed — EXIF coords); trip labels enriched; `clusterByPlace()` "N trips" badge.
- **Phase 19 — Duplicate Detector:** `duplicateDetector.ts` (≤600 recent, batch-resolve 50, 3s sliding window, suggestedKeepIndex); `duplicateStore` (scan progress, deleteFromGroup, dismissGroup); `duplicates.tsx` 3-state UI; entry via Albums toolbar.
- **Phase 20 — Bug Fixes & Polish:** DB-init race fix (`_dbPromise` memoization, PRAGMAs separate); memories race fix (`loadTrips` on mount, `memoriesGroupedAtRef`); Save-as-Album consolidated onto TripCard; album drag-to-select parity with gallery.
- **Phase 21 — Recycle Bin / Soft Delete:** `trash` table; `trashStore` (moveToTrash/restore/permanentlyDelete/emptyTrash/purgeExpired 30d); soft-delete intercept in detail + selection; `UndoToast` provider; gallery client-side trash filtering + `invalidate()`/`refreshKey`; `trash.tsx`; startup purge.
- **Phase 22 — Onboarding & Empty States:** `onboarding.ts` (secure-store flag); onboarding gate in `_layout`; `onboarding.tsx` 4-slide flow; `PermissionsEmptyState` (all 3 tabs); `GalleryEmptyState`/`TripsEmptyState`/`AlbumsEmptyState`; added `react-native-svg`.
- **Phase 23 — People Tab (Face Clustering):** `faceDetector.ts` (ML Kit landmark embedding, normalized); `faceClusterer.ts` (greedy NN, centroid avg); `face_embeddings`/`face_clusters` tables + helpers; `peopleStore` (batch 10, skip scanned, MIN_CLUSTER_SIZE 3); `people.tsx` 3-state UI; `PersonCard`; `people/[id].tsx`; photo context 'person'; People as 4th tab.
- **Phase 24 — UI Polish & Alert Cleanup:** unified cross-platform TextInput rename modal; animated camera mode switcher + haptics + press feedback; 0.5× ultrawide hidden on Android; flash cycle off/on/auto, `animateShutter={false}`; zoom calibration for flagship Android.
- **Phase 25 — Camera Save + Background People Scan:** `_createAssetAsync` legacy path; MODIFICATION_TIME sort + getModificationTime fallback; 2s delayed invalidate; non-blocking background scan + compact banner + completion notification; replaced ML Kit landmarks with `react-native-fast-tflite` MobileFaceNet (192-d L2-normalized, threshold 1.0); Gradle 9.3.1→8.13; `removeAllListeners` scope fix.
- **Phase 26 — True HeadlessJS Background Scan:** `@supersami/rn-foreground-service` (bypassed wrapper, direct `NativeModules.ForegroundService`); manual AndroidManifest FOREGROUND_SERVICE_SPECIAL_USE + service decls; `withForegroundService.js` config plugin; `scan_progress` IPC table; `faceScanHeadless.ts` (zero React deps, GathrFaceScanTask); `index.ts` headless registration before expo-router/entry; peopleStore SQLite-polling mode w/ in-process fallback; gradlew direct-install build approach.
- **Phase 27 — People Tab UI Polish (Design Handoff):** custom `PeopleHeader` ("N people" + rescan icon); frosted rescan dropdown (Rescan / Wipe & rescan); redesigned scan banner card (`scanScanned`/`scanTotal` added to peopleStore); edge-to-edge 2-col PersonCard grid (gap 2, LinearGradient scrim, inline rename ring); GathrMark chevron empty state; manual row-based ScrollView instead of FlashList numColumns; tap → `people/[id].tsx`.
- **Phase 28 — Clean-Up Dashboard (Design Handoff):** new `app/cleanup.tsx` 5-state machine (entry→scanning→results→stack→allClean); runs `duplicateStore.scan()`; per-category swipe card-stack (left=trash via `deleteFromGroup` all-but-`suggestedKeepIndex`, right=keep via `dismissGroup`); dupes wired live; `near`/`blurry`/`videos` commented-out TODO stubs (no backing detection); `/cleanup` not yet wired to a tab; `duplicates.tsx` left intact.
- **Phase 29 — Photo Notes & Tags:** `photo_notes` table (asset_id PK, note_text, timestamps) + `photo_tags` table (asset_id+tag composite PK, lowercase-normalised); `notesStore.ts` (notes+tags keyed by assetId, optimistic writes); `PhotoNotesSheet.tsx` (peek/expanded bottom sheet, drag-handle PanResponder, note TextInput, tag chips, Save pill); "Note" ActionButton wired into `photo/[id].tsx` footer + dim overlay.
- **Phase 30 — Trips Tab Redesign (Design Handoff):** `TripCard` full redesign (cover-on-top + dark `#0C0C0E` body, `large?` prop for first card, BlurView "Save as Album" pill, "In Albums" checkmark badge via `inAlbums?` prop); `TripsSection` exports `clusterByPlace` + `TripCluster`; `trips.tsx` rewrite (header + search toggle, MemoriesSection on top, "RECENT TRIPS" label, vertical ScrollView, first cluster large, `saveSuggestionAsAlbum` wired, Regroup button removed).
- **Phase 31 — Gallery Redesign (Design Handoff):** accent recolored from iOS blue to muted purple (`#A488BE` dark / `#7B5EA7` light) + `selectedOverlay`/`glass`/`glassBorder` updated in `theme.ts`; `GalleryTitleBar` component in `index.tsx` replaces floating search FAB — shows "All Photos" title + search icon + "Select" button in normal mode, switches to "By month" pill / selected-count / "All" pill in selection mode; `startSelecting()` action added to `selectionStore`; `PhotoThumb` selection indicator replaced from `Ionicons ellipse-outline/checkmark-circle` to custom bordered circle + checkmark `View` (`selCircle` + `checkmark` styles); `DateSectionHeader` returns zero-height `View` when not selecting (headers hidden in browse mode), simplified to static `StyleSheet`, circle border uses `rgba(255,255,255,0.30)` unfilled / accent filled.
- **Phase 32 — Albums Tab Redesign (Design Handoff):** `AlbumCard` redesigned to edge-to-edge 2-col grid (gap 2, `CARD_SIZE`/`GRID_GAP` exported, `LinearGradient` scrim, inline name+count labels, `onLongPress` prop, `GlassView` lockBadge replaced with plain `View`); `albums.tsx` adds `AlbumContextMenu` (cover badge, Rename/Share/Make Private/Delete actions), `RenameSheet` (styled bottom-sheet TextInput, accent-purple Save pill), `DeleteConfirm` modal; `albumStore` adds `renameAlbum` + `toggleAlbumPrivate` actions; `db.ts` adds `renameAlbum` + `setAlbumPrivate` helpers.
